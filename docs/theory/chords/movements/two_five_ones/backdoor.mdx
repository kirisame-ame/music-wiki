# Backdoor Progression

The backdoor cadence commonly uses **iv7–♭VII7–I**. In C: **Fm7–B♭7–Cmaj7**. A related form starts on ii: **Dm7–B♭7–Cmaj7**.

## Common variations

- B♭9 or B♭13 for a fuller ♭VII chord
- **A♭/B♭** for a B♭9sus4 voicing
- Cmaj9 or C6/9 as a softer tonic landing
