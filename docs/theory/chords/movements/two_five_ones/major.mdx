# Major 2–5–1

The common jazz form is **ii7–V7–Imaj7**. In C: **Dm7–G7–Cmaj7**.

## Common variations

- **ii:** Dm9, Dm11, Dm13; Fmaj9/D for a wider Dm11 voicing
- **V:** G13, G7sus4–G7, or G/B for a rising bass line
- **I:** Cmaj9, C6/9, Cmaj13♯11, or the slash-chord voicings C/E and C/G
- **Leading tone:** Bdim7 can stand in for a rootless G7♭9
